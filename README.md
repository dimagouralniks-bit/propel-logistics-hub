# Propel Logistics Hub — MVP preview

A clickable inventory / 3PL operations MVP concept, adapted from the Warevolve warehouse app.

**All data is fictional demo data** (example clients, SKUs, warehouses, carriers). Nothing connects to a backend; changes are saved only in the visitor's browser (localStorage). Use “Reset demo data” in the menu to start again.

Pages: Dashboard · Inventory · Receiving · Dispatch · Orders · Clients · Customise.

Run locally: `npm install && npm run dev`. Build: `npm run build` (static output in `dist/`).
